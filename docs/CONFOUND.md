## How to read this

* **LOSO up + source predictability down** vs baseline => the transform removed a real recording-source shortcut and bought genuine cross-domain generalisation from data we already have.
* **LOSO flat while source predictability drops** => the source signal and the fault signal are entangled in the same directions; you cannot separate them linearly with 3 sources, and a 4th independent domain is required.
* **all-sources balAcc must not collapse** -- if it does, the transform destroyed the in-domain signal and is not worth keeping.
