## Source confound (the dataset's structural risk)

When fault/normal correlates with the recording source, the model can take a shortcut. Predicting the recording **source** from the embedding alone scores balAcc 0.533±0.05 (MCC 0.711) — the shortcut is *available*. Trust the **source-held-constant** rows above (one per source with both classes), not the all-sources row, whose AUROC is confound-inflated.
